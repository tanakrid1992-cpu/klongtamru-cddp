# CDDP v3 · ระบบข้อมูลเมืองดิจิทัล เทศบาลตำบลคลองตำหรุ

หน้าเว็บอยู่บน **GitHub Pages** · ข้อมูลอยู่ใน **Google Sheet** ผ่าน **Google Apps Script API**

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด (UI + แผนที่) |
| `config.js` | ใส่ URL ของ Apps Script |
| `geo.js` | ขอบเขตเทศบาล / ถนน 26 เส้น / ทางน้ำ 7 เส้น |
| `Code.gs` | API ฝั่ง Google (ไม่ต้องขึ้น GitHub) |

## ติดตั้ง (ครั้งเดียว)
1. เปิด Google Sheet → **ส่วนขยาย › Apps Script** → ลบโค้ดเดิม วาง `Code.gs` → บันทึก
2. เลือกฟังก์ชัน `setup` → **เรียกใช้** → อนุญาตสิทธิ์ → ดู **รหัสผ่าน admin ชั่วคราว** ใน Execution log
3. **ทำให้ใช้งานได้ › การทำให้ใช้งานได้รายการใหม่ › เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน** → คัดลอก URL (ลงท้าย `/exec`)
4. วาง URL ใน `config.js` → `window.CDDP_API = 'https://script.google.com/macros/s/.../exec';`
5. อัปโหลด `index.html`, `config.js`, `geo.js` ขึ้น GitHub → **Settings › Pages** → Branch `main` / root
6. เข้าเว็บ → ล็อกอิน `admin` → เมนูมุมล่างซ้าย › **เปลี่ยนรหัสผ่าน** ทันที
7. (แนะนำ) รันฟังก์ชัน `createDailyBackup` เพื่อสำรอง Sheet อัตโนมัติทุกวัน

> แก้ `Code.gs` ภายหลัง → ต้อง **จัดการการทำให้ใช้งานได้ › แก้ไข › เวอร์ชันใหม่** (URL เดิม)

## หมายเหตุ
- ชีตข้อมูลตั้งชื่อตามหมวด (เช่น `ครัวเรือน หมู่ 1`) — ระบบสร้างให้อัตโนมัติเมื่อบันทึกครั้งแรก
  ถ้ามีชีตเดิมอยู่แล้ว ระบบอ่านหัวคอลัมน์จากแถวที่ 1 และเติม `id` ให้แถวที่ยังไม่มี
- คอลัมน์บังคับ: `id`, `lat`, `lng` (+ `ts`, `updated_by` บันทึกอัตโนมัติ)
- รหัสผ่านเก็บแบบ hash + salt · ทุกคำขอต้องมี token · เลขบัตรประชาชนถูกปิดบังสำหรับผู้ไม่มีสิทธิ์ PDPA
- ชีต `Log` บันทึกการเข้าระบบ/เพิ่ม/แก้ไข/ลบ ทุกครั้ง
- ถ้า `config.js` ว่าง = โหมดทดลอง (เก็บในเบราว์เซอร์)
